# Mushaf QCF v1 Page Fonts — Mirror

Per-page TrueType fonts of **Mushaf al-Madinah** (QCF v1, 1405H edition), 604 files,
produced by the **King Fahd Glorious Qur'an Printing Complex (KFGQPC)** —
مجمع الملك فهد لطباعة المصحف الشريف — to whom, and to whom alone, these fonts
are attributed, as their published permission requires.

This repository is a plain static mirror serving the نظام مراكز القرآن mobile app
(a free, non-commercial Qur'an memorization platform). Files are byte-identical to
the KFGQPC originals as distributed via the qpc-fonts community mirrors:
**no file has been modified in any way** (a condition of the KFGQPC license),
and nothing here is sold.

- `fonts/QCF_P001.TTF` … `fonts/QCF_P604.TTF` — one font per mushaf page
- `manifest.json` — SHA-256 of every file; the app verifies each download against
  the same manifest bundled inside it before ever rendering a glyph

KFGQPC usage terms (summary): free use including websites and software; attribute
to KFGQPC only; do not modify the font files; do not sell the fonts themselves.
